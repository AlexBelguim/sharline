# FX textures

- `impact_decal.png`: bullet hole decal (256 px, straight alpha). Made with Krea2 Turbo (local ComfyUI,
  `tools/comfy_gen.py`, seed 33, 768 px). Prompt: a single stylized bullet impact hole seen straight on in a flat
  light grey plaster wall, with radial hairline cracks and a dusty scorch ring, flat lighting. The plaster
  around it was keyed out (difference from the median background colour, plus a radial falloff).
